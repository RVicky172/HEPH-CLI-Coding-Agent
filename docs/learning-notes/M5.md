# M5: Craftsmanship in the CLI (run · init · HEPH.md · audit log), learning notes

**Goal:** heph becomes a tool you use every day: one-shot tasks in scripts, per-project rules, and a record of everything it did.

## New commands

```powershell
heph run "fix the failing test"                  # one task, then exit
cat error.log | heph run "explain this error"    # piped input becomes context
heph run "summarise the changes" --json          # JSON lines for scripts/CI
heph run "format the code" --mode auto-edit      # without a terminal, nobody can approve → choose a mode
heph init                                        # HEPH.md + .heph/config.json + .heph/.gitignore
heph config                                      # effective settings, where they came from, secrets masked
```

Exit codes of `heph run`: **0** done · **1** error · **2** stopped at max steps · **130** Ctrl+C.

## Key ideas

| Concept | Where | Why |
|---|---|---|
| One session builder for chat AND run | `container.ts` `createAgentSession()` | same tools, permissions, audit and instructions in both modes. No drift |
| Swap the UI, not the agent | `ui/JsonOutput.ts` implements `OutputSink` + `Approver` | `--json` is just another output. The Agent can't tell (Liskov Substitution) |
| Non-interactive = deny | `JsonOutput.ask()`, `TerminalUI.ask()` without a TTY | a script can't say "yes", so changes need an explicit `--mode` |
| Piped stdin | `readPipedStdin()` | waits briefly if stdin is open but empty (CI), caps at 200 KB, wraps it in `<stdin>` tags |
| Project instructions | `project/ProjectInstructions.ts` → system prompt | `HEPH.md` (or `AGENTS.md`), capped at 20 KB. Marked as **unable to change permissions**, because it is repository content anyone could have written |
| `heph init` | `project/ProjectInit.ts` | detects useful `package.json` scripts. Never overwrites without `--force` |
| Audit log | `logging/JsonlAuditLog.ts`, recorded in `ToolExecutor.run()` | every call: time, session, tool, label, args (long strings cut), outcome ok/failed/**denied**, duration. Logging can never crash the agent |
| JSON Lines | `.heph/logs/audit-YYYY-MM-DD.jsonl` | append-only, one event per line: `Get-Content … \| ConvertFrom-Json` |

Read your audit log:
```powershell
Get-Content .heph\logs\audit-*.jsonl | ConvertFrom-Json | Format-Table time, tool, label, outcome
```

## Testing: a real end-to-end test
`tests/e2e/run.e2e.test.ts` starts **the real CLI as a child process** (via tsx, no build needed) against a ~40-line fake OpenAI server. It checks:
- `--json` events, exit code 0, the file content reaching the model, the audit log written to disk
- piped stdin arriving inside the user message
- **SAFETY:** without a terminal, `write_file` in ask mode is NOT applied and the model is told `NOT APPLIED`
- `--mode auto-edit` lets a script write
- a server that is down gives exit code 1 and "Could not connect"

This is the test level closest to real usage: no mocks inside heph at all.

## Observed with the real model
With a `HEPH.md` rule "answer in exactly one sentence, ending with FORGED", Qwen ended with FORGED but wrote several sentences. **Instructions steer models; they don't bind them.** That's exactly why safety lives in code (PermissionGate, PathGuard) and never only in prompts.
